CN CONCEPTS
What is encapsulation?

As data moves down the sender's protocol stack, layers add control information. The transport layer creates a segment/datagram, the network layer creates an IP packet, and the data-link layer creates a frame.

Why does routing happen at Layer 3?

Routers use network-layer addresses and routing information to select a next hop. Dijkstra is used here as a simplified shortest-path algorithm; this is not a full implementation of OSPF.

Why do MAC addresses change?

On each routed link, the router removes the incoming frame and builds a new frame for the next hop. The IP source and destination normally remain unchanged in this basic example.

What does decapsulation do?

The receiver processes the frame, packet and transport data, removes their conceptual wrappers, and delivers the original payload to the application.
